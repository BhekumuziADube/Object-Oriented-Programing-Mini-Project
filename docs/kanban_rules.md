| --- | --- | --- |

| In Review | Pull request open, waiting for a teammate | 3 in total |
| Done | Pull request merged into develop, issue closed | none |

## Rules

- One card = one issue = one branch = one pull request into develop.
- Start a new card only when you are under your limit. If a teammate is waiting for a review, review first.
- Pull requests need approval from someone other than the author before merging.
- Write "Closes #n" in the pull request so the issue closes by itself.
- Hold a short daily stand-up: what I finished, what I am doing, what is blocking me.
